# Меню säwir для планшета — памятка для правок

Электронное меню кофейни säwir (Уральск) для планшета в зале.
Живой адрес: https://inforaimartist-dotcom.github.io/sawir-menu/ — GitHub Pages, ветка `main`, корень репозитория.
Любой push в `main` публикует сайт за 1–3 минуты.

## Где что лежит

- `index.html` — вся страница. Все позиции меню лежат в `const MENU` внутри `<script>`:
  разделы → `subs` (категории) → `items`.
  Поля позиции: `img` (имя файла в `img/` без `.webp`), `name`, `kz` (название на казахском),
  `desc` (состав), `k: [ккал, белки, жиры, углеводы]`, `w` (вес или объём), `price` (тенге), `t` (`'хит' | 'новое' | 'острое'`).
- Порядок разделов на экране задаёт строка `MENU.unshift(MENU.splice(1, 1)[0])`: Кухня → Напитки → Десерты.
- `img/` — фото. Префикс `k-` у кухни, `d-` у десертов, `dr-<id>` у напитков (id взят с сайта sawir.dzumba.kz).
  Кухня и десерты: квадрат 1000 px, прозрачный фон, мягкая тень, блюдо занимает 86% кадра.
  Напитки: квадрат 900 px на белом.
- `version.json`, `sw.js`, `manifest.webmanifest`, `icon-*.png` — работа в режиме киоска:
  фото сохраняются на планшете, обновления подтягиваются сами.

## После любой правки

1. В `index.html` поменять `const VERSION`. Если менялись фото, поменять и `const IMG_V`.
2. Записать то же значение в `version.json`.
3. Закоммитить и запушить в `main`.

Планшет раз в 5 минут проверяет `version.json` и перезагружается, когда 2 минуты никто не трогает экран.

## Решения владельца (не менять без просьбы)

- Белый фон. Бордовая версия была отклонена.
- Заставки при простое нет: меню всегда открыто.
- Цена стоит отдельной строкой по центру, сразу под строкой «вес · КБЖУ».
- На экране 32″ (1920×1080) все категории внизу видны без прокрутки (функция `fitSeg`).
- Ничего не выдумывать: если у позиции нет состава, КБЖУ или объёма, поле просто не показывается.

## Новые фото блюд

Генерировать в Higgsfield, модель `gpt_image_2_6`:
- `background: transparent`, `quality: high`, `resolution: 2k`;
- в качестве референса — кадр блюда из фото печатного меню;
- промпт: то же блюдо целиком, без фона, без текста.

Потом обработать: обрезать по альфа-каналу, вписать в квадрат 1000 px на 86%, добавить тень
(смещение 1% / 2,2%, размытие 2%, непрозрачность 0,30), сохранить в WebP с качеством 84.
